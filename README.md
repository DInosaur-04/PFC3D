## 项目简介：基于AutoML算法的PFC3D细观参数智能反演
这是论文《Multi-Objective Automated Machine Learning for Inversion of Mesoscopic Parameters in Discrete Element Contact Models》所对应的代码，该资源库里包含了论文所提及的AutoML算法代码以及ANN算法代码。论文内容在开源期刊Applied Science上可找到。

请在jupyter笔记本里打开代码

该项目基于PFC3D线性平行黏结模型，设计正交实验方案，系统变化7个细观参数（弹性模量E、刚度比ks/kn、退化模量Ed等），完成361组单轴压缩数值模拟；从每条应力-应变曲线中提取8个关键特征点（16维输入），构建训练数据库。基于AutoKeras框架，构建多输出回归模型，自动搜索最优网络架构，最优网络架构包含2层隐藏层（256和32个神经元，采用ReLU激活函数），算法采用自定义加权MSE损失函数（权重分别为0.01/0.1/0.89），实现E、ks/kn、Ed三个细观参数的同步反演。模型在测试集上取得R²分别为0.992（E）、0.710（ks/kn）、0.521（Ed）；同时采用了Sobol全局敏感性分析法量化16个输入特征对三个输出参数的影响贡献，揭示关键控制变量（如y6对E的决定性影响），为参数优先排序提供了理论依据。实验设计3组不同配比（P/W=2.0/2.7/3.5）的石膏试样单轴压缩实验以验证数据反演结果，获取真实应力-应变曲线，利用训练好的AutoML模型反演细观参数；将反演参数代入PFC3D进行正演模拟，数值与实验曲线高度吻合，验证了模型在实际工程场景中的可靠性与泛化能力。同时，实验构建了传统ANN模型作为基准，对比AutoML在自动化调参和建模效率上的优势，AutoML以相近精度（R²差异<0.05）大幅减少了人工调参工作量，证明了其在数据稀缺工程问题中的实用价值。
